The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Each . ? and : is followed by 2 new lines:

    >>> text_indentation("Hello. How are you? Fine: thanks")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks

Spaces at the start and end of lines are removed:

    >>> text_indentation("   Hi.    There   ")
    Hi.
    <BLANKLINE>
    There

Text with no special characters is printed as it is:

    >>> text_indentation("No punctuation here")
    No punctuation here

A text ending with a special character:

    >>> text_indentation("End.")
    End.
    <BLANKLINE>

An empty string prints nothing:

    >>> text_indentation("")

A number instead of text:

    >>> text_indentation(12)
