The ``1-my_list`` module
========================

Using ``MyList``
----------------

First get the class:

    >>> MyList = __import__('1-my_list').MyList

MyList is a list:

    >>> issubclass(MyList, list)
    True

An empty list prints as an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Items print sorted, but the list itself does not change:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Negative numbers sort correctly:

    >>> neg = MyList([3, -1, 0, -7])
    >>> neg.print_sorted()
    [-7, -1, 0, 3]

An already sorted list stays the same:

    >>> MyList([1, 2, 3]).print_sorted()
    [1, 2, 3]

Repeated values are kept:

    >>> MyList([2, 1, 2]).print_sorted()
    [1, 2, 2]

print_sorted returns a new list each time, so the original is untouched:

    >>> a = MyList([3, 1])
    >>> a.print_sorted()
    [1, 3]
    >>> a
    [3, 1]
